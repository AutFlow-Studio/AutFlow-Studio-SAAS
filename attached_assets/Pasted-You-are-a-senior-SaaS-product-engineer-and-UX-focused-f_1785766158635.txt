You are a senior SaaS product engineer and UX-focused full-stack developer.

Your task is to transform the application into a specialized **Clinic / Healthcare Workspace MVP**.

The goal is NOT to create a generic CRM with different names.

The goal is to make the workspace feel specifically designed for clinics.

This is an MVP, so prioritize:

* Real usability
* Clean experience
* Strong demo value
* Simple maintainable architecture

Avoid unnecessary complexity.

---

# Core Goal

When a user selects:

"Clinic / Healthcare"

during onboarding, the application should load a dedicated clinic workspace.

The user should feel:

"This system was built for my clinic."

---

# Terminology Changes

Inside the clinic workspace, use healthcare terminology.

Replace:

Client → Patient

Project → Treatment Plan (where applicable)

Meeting → Appointment

Task → Clinic Task

Invoice → Billing

Notes → Medical Notes

Keep terminology consistent across:

* Sidebar
* Pages
* Buttons
* Forms
* Empty states
* Dashboard

Create a dedicated patient management system.

Each patient should include:

* Full name
* Phone number
* Email
* Date of birth
* Gender
* Address
* Status
* Notes
* Created date

Patient profile should contain:

## Overview

## Appointments

Previous and upcoming appointments.

## Treatments

Treatment history.

## Billing

Payment information.

## Documents

Uploaded files.

## Activity Timeline
