Act as a senior SaaS Product Architect and Full-Stack Engineer.

The onboarding currently asks users to choose an industry, but **every option creates the exact same workspace**. This defeats the purpose of industry selection.

I want **true industry-specific workspaces**, not just different labels.

### Goal

Each industry must have its own customized workspace, terminology, navigation, default modules, starter data, dashboards, forms, AI context, and workflows.

The user should immediately feel that the product was built specifically for their business.

## AI Customization

The AI Assistant must automatically know which workspace type the user selected.

Examples:

Agency:
"Which client has overdue invoices?"

Clinic:
"Which patients have appointments tomorrow?"

Consulting:
"Summarize my active engagements."

Freelancer:
"How much did I earn this month?"

The AI should answer using the correct terminology and only reference the modules available in that workspace.

---

## Technical Requirements

* Store the selected industry in the workspace configuration.
* Load a different workspace configuration for each industry.
* Allow each industry to have:

  * Different navigation
  * Different terminology
  * Different database labels where appropriate (Clients → Patients)
  * Different dashboard widgets
  * Different starter templates
  * Different default task templates
  * Different AI context
  * Different onboarding checklist
* Build the architecture so new industries can be added easily in the future by creating a new configuration instead of modifying the entire application.
* Keep one shared codebase while making each workspace feel purpose-built for its industry.
