You are a senior SaaS product engineer and UX-focused full-stack developer.

Your task is to transform the application into a specialized **Freelance Developer Workspace MVP**.

The goal is NOT to create a generic project management tool.

The goal is to create a workspace designed specifically for independent software developers who manage clients, projects, tasks, deadlines, and payments.

This should feel like a product built for freelance developers.

Focus on:

* Practical workflow
* Clean UX
* Strong demo value
* Simple maintainable architecture

Avoid unnecessary complexity.

---

# Core Goal

When a user selects:

"Freelancer Developer"

during onboarding, the application should load a dedicated freelancer workspace.

The user should feel:

"This system understands how I work as a freelance developer."

## Client Overview

* Active clients
* Recent client activity

## Financial Overview

* Monthly income
* Pending invoices

* Tasks completed

# Clients Module

Create a client management system designed for freelancers.

Each client should include:

* Name
* Company (optional)
* Email
* Phone
* Notes
* Project history
* Invoice history
* Created date

Client profile should contain:

## Projects

Recent actions.
